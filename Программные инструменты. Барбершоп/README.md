# No-Show Predictor: EDA для прогноза неявки клиента барбершопа

Разведочный анализ данных по задаче прогнозирования неявки клиента в барбершоп.

Цель — научиться заранее оценивать риск того, что клиент не придёт на запись. В перспективе это поможет администратору точечно подтверждать визиты и планировать загрузку мастеров.

## Данные

Реальной выгрузки CRM нет, поэтому в ноутбуке генерируется синтетический датасет: 6000 записей, 24 столбца, фиксированный `random_state`. Он воспроизводим и подходит для демонстрации пайплайна EDA, но не описывает реальное поведение клиентов барбершопа.

Признаки: профиль клиента, параметры визита, календарные признаки, факт и время отправки напоминания.

## Задача

Бинарная классификация. Целевая переменная `no_show`: 1 — клиент не пришёл, 0 — пришёл. Прогноз делается за 24 часа до визита. Признаки, известные позже этого момента, использовать нельзя.

## Метрики

Классы несбалансированы, поэтому accuracy не подходит. Используются ROC-AUC, Average Precision, Precision и Recall класса 1, матрица ошибок. Порог выбирается с учётом того, что пропущенная неявка дороже лишнего звонка.

## Содержание ноутбука

Постановка задачи, генерация датасета, первичная проверка, распределение целевой переменной, анализ календарных и клиентских признаков, категориальные признаки, выбросы, корреляции, краткие итоги.
